# Jaam's Archaeology

A Minecraft Forge 1.20.1 mod focused on expanding archaeology. Discover ancient artifacts, unearth hidden treasures.

## Content

- **Weapons** — Primitive Spear, Sword of Undying, and repairable weapon fragments like the Spear Fragment and Broken Sword Fragment
- **Ammonites** — Shiny, Petrified, and Ossified Ammonites that can be fired as projectiles
- **Mud Idols** — Strange, Traitor's, Skeletal, Guardian, Explosive, Rotten, and Arthropod's Idols, each granting a unique Vigor effect
- **Enchantments** — Atonement, Vengeance, and Strikehold

## Requirements

- Minecraft 1.20.1
- Forge 47.x
- Java 17
